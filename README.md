# E-commerce Sales Analysis

## Project Overview
This project focuses on analyzing e-commerce sales data using Microsoft Excel to identify sales trends, evaluate business performance, and generate insights that support data-driven decision-making.

## Tools Used
- Microsoft Excel
- Data Cleaning and Preparation
- Data Analysis
- Data Visualization

## Project Files
- `E_commerce excel project` — Excel project file containing the analysis.

## Key Objectives
- Analyze sales performance and trends.
- Explore the data to identify useful business insights.
- Present findings in a clear and organized way.
